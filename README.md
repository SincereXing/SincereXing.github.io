# 智能米字格练字帖生成器

## 项目简介
起因是家里小孩开始认字，同时也希望小孩通过练字来加强对字的记忆和理解，但是网上的字帖或者买来的字帖顺序都是固定的，和小孩的学习进度无法匹配，所以就想着开发一个练字帖生成器，最近AI生成比较火，就用AI生成了一个，欢迎大家一起使用。
网站地址：http://sincerexing.github.io/

所以整体是专为中文学习者设计的AI练字辅助工具，支持：

- 单字/多字智能生成米字格字帖
- 一键打印A4标准练字纸
- 适配儿童及成人不同学习阶段

## 核心功能

✅ **智能生成**：输入1-50个汉字自动生成规范化字帖  
✅ **专业排版**：符合国家《通用规范汉字表》笔顺标准  
✅ **多场景适配**：

   - 儿童笔顺练习
   - 外国人汉字书写训练
   - 书法爱好者临摹素材

## 快速上手

1. 输入框填写要练习的汉字（如：中华文明上下五千年）
2. 点击生成按钮预览效果
3. 点击打印A4进行练字帖打印
